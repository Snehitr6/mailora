# Mailora – Email Management Web Application

Mailora is a modern email management web application built with React and Vite. It provides a clean, responsive interface for organizing emails, managing folders, composing messages, and tracking important conversations.

## 🚀 Features

- **Inbox Management** – View and organize received emails.
- **Email Search** – Search emails by relevant details.
- **Starred Emails** – Mark important emails for quick access.
- **Snoozed Emails** – Temporarily postpone emails.
- **Sent Emails** – View sent messages.
- **Drafts** – Save unfinished email messages.
- **Archive** – Keep emails without cluttering the inbox.
- **Spam Management** – Organize unwanted messages.
- **Trash** – Manage deleted emails.
- **Bulk Actions** – Select multiple emails to manage them together.
- **Email Composition** – Compose and send messages within the application.
- **Responsive UI** – Designed for desktop and mobile screens.
- **Local Storage** – Persist email data in the browser.

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript (ES6+)
- Tailwind CSS
- React Router DOM
- Lucide React
- Browser Local Storage
